# 实验约定：sampled-uplink-v1

## 对象和反馈

所有状态、输入与代价均为归一化教学量，时间单位为秒。目标为零。

- 一阶对象：`dx/dt = x + u + w`，默认 `x(0)=1`；反馈 `u=-kp*y`。
- 位置—速度对象：`dp/dt=v, dv/dt=u+w`，默认 `(p,v)=(1,0)`；反馈 `u=-kp*y_position-kd*y_velocity`。

每步保持输入和扰动常数，状态用这两个方程的精确保持输入解推进，不用 Euler 更新。输入限幅，检测超过声明状态范数上限时停止。限幅和状态上限均为仿真约定，不认证安全性。

## 时序与信息

自定义本地对象按[模型接口](own-model.md)声明实际动力学、布局、单位和来源；工厂逐运行重建。内置保持输入公式和网格参考只对应上面的两个方程，不能据此证明用户积分器精确。

在 `t=0,dt,...,T-dt` 各时刻：

1. 传感器采样当前状态，加上该时间步的测量噪声。
2. 发送策略依据本地测量、上次尝试发送的值和时间决定是否请求发送；不读取接收端未公开的状态。
3. 若预算尚有余额，尝试发送，立即计入预算。丢包由该时间步固定的外部随机数决定；未丢失的消息进入固定整数步延迟队列。
4. 到达本时刻的消息交给控制器。零延迟消息可以当场到达；没有消息时不重新调用控制器，执行器继续保持上一次限幅后的输入。还没有收到第一条消息时输入为零。
5. 保存当前真值、控制器可见值与通信事件，然后按保持输入解推进一步。

`T` 只保存末状态，不再发送、到达或计算控制。此时及之后到达的消息仍计“在途”。真值曲线是评估者的事后信息，不是控制器输入。

## 三种发送策略

三种策略使用相同的最大发送次数 `B`，包括初始发送及丢失的包。并不强迫实际发送次数相同。

- 周期：将 `B` 个机会放在时间步 `floor(i*N/B), i=0,...,B-1`。`B=0` 不发送。这样不会把预算集中耗在开头。
- 绝对变化：初始请求发送；之后当 `norm(y-y_last_sent) >= delta`，或距上次尝试达到 heartbeat 时请求。
- 相对变化：初始请求发送；之后比较 `norm(y-y_last_sent) >= sqrt(delta^2 + sigma^2*norm(y)^2)`，并保留同一 heartbeat。

`y_last_sent` 在尝试发送时更新，即使消息后来丢失；当前没有 ACK 或重传模型。预算用完后请求被记录为受限，不产生隐含的免费发送。判断仅在固定采样网格上执行；网格限制不是连续时间无 Zeno 或闭环稳定性证明。

Heartbeat 转为整数步：将 `heartbeat/dt` 距最近整数不超过该比值 4 个 ULP 的情况视作整点，其余向上取整。该数值约定避免 `0.14/0.02 = 7.000000000000001` 被误取为 8 步；`0.140001/0.02` 仍取 8 步。ULP 是该浮点数的相邻表示间距，见 [Python 数学函数说明](https://docs.python.org/3.10/library/math.html#math.ulp)。每次导出保留请求值、有效步数和有效间隔；周期策略不使用 heartbeat。有效间隔是事件触发的后备请求间隔，预算耗尽、丢包和在途消息仍按上面的规则处理，不保证接收端按该间隔收到更新。

## 随机输入与公平范围

测量噪声、输入扰动和网络丢包使用独立固定种子流，先按时间步完整生成，再供所有策略使用。相同时间步的潜在丢包结果相同，不因某策略之前少发一个包而平移后续噪声。

改变阈值会改变真实状态和测量值，但不改变底层标准噪声与网络随机轨迹。控制器与发送端的允许信息类型相同，实际收到的测量子集不同；这正是实验变量。当前只比较上行消息数量，未建模下行网络、包头、带宽排队、字节能耗或硬件计算耗时。

## 指标

- 位置 RMSE：位置平方在时间上的梯形积分除以完整 `T` 后开方。只对完整时段输出；提前失败不以较短时段的低均值参与比较。
- 二次代价：梯形积分 `position^2 + 0.1*velocity^2`，加保持输入矩形积分 `0.01*u^2`；一阶对象没有速度项。这是约定代价，不是物理能量。
- 信息年龄：控制器最后收到消息的采样时刻到当前时刻的差。均值是已有观测的检查时刻上的算术平均，不是连续时间年龄积分；同时报告尚无观测的步数，全程无观测时为 `null`。
- 消息账本：`attempted = delivered + dropped + in_flight`。到达次数、控制器调用、传感器采样、变化量范数检测和预算受限请求分别记录。

计算调用次数不是 CPU 实测耗时，仿真耗时不是人工节时。一次演示不支持任何策略普遍优越、论文复现成功、真实采用或稳定性认证的结论。
