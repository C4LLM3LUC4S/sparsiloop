# SparsiLoop 0.1.0a3

这版让本地结果更容易留住：选择或复核已经算完、报告却没能保存完整时，会留下完整记录，并打印重绘命令。保存位置恢复可用后，照着命令生成报告即可，不用重新训练、选择或测试。原策略、已用编号和执行环境仍在记录里。

## 下载和开始使用

- **`SparsiLoop-0.1.0a3.zip`**：推荐首次使用。包含离线安装包、对应源码、示例和 `START_HERE.md`。
- `sparsiloop-0.1.0a3-py3-none-any.whl`：已有 Python 3.10+ 独立环境时安装；核心不需要第三方运行依赖。
- `sparsiloop-0.1.0a3.tar.gz`：源码分发包。
- `RELEASE_INFO.json` 和 `SHA256SUMS`：核对对应源码、大小与 SHA-256。

完整解压 ZIP。在 Windows 下载目录运行 `(Get-FileHash .\SparsiLoop-0.1.0a3.zip -Algorithm SHA256).Hash`，与同名校验条目比较。包内 `BUILD_INFO.json` 标明源码，`MANIFEST.json` 用于核对内容。旧结果与旧发行包单独保留。

## 遇到保存问题，怎么接着做？

1. 输出已存在，或上级路径是文件：程序会在读取输入、计算结果前停下。用 `--out` 换一个新目录，原结果先留着。
2. 本地 planned/history 导出中途报错，并给出 **Full record retained**：先保留那个完整 JSON，再按打印的命令重绘到新目录。路径带空格或单引号也可以直接使用打印的 PowerShell 命令。
3. 最初的备用记录也没能完整写入：程序不会承诺可以恢复。先解决磁盘空间或权限问题；保留原输入和已有结果，再按原任务决定是否重试。

具体文件用途和本地命令见[保存中断后的恢复](../source-recovery.md#算完了报告却没能保存完整)。这个恢复用于本地选择与历史导出；网页临时 ZIP 不会给出一个随后已被删除的本地文件路径，也没有新增浏览器下载恢复功能。

## 还改了什么？

发行流程现在能在列表暂时查不到草稿时，通过 GitHub 的正式接口核对同一草稿的编号、标签和源码，并有界等待。无法核实时保留原草稿，不重建或替换资产。

模型、控制器、选择规则、数值结果和历史格式没有改变。报告生成成功不代表任务达标；仍应先声明要求，查看具体未达标编号，再按原计划复核和保存完整历史。受控文件错误检查属于开发者验证，不是外部用户丢失、硬件效果或独立采用的证据。

## English

This maintenance alpha rejects unusable output paths before reading saved inputs or starting a calculation. Local planned/history exports retain a complete typed record before rendering. A later I/O failure or interruption prints its actual location and a redraw command using the same interpreter; redraw performs no training, selection or test runs. Conditions, Q tables, known IDs and execution context stay intact. An incomplete initial recovery write is never advertised as a complete backup.

Temporary web ZIP exports opt out of local recovery; browser-download recovery is not added. The release helper also handles temporarily missing draft-list entries through an identity-checked, bounded lookup without replacing old assets. Use the complete offline bundle with Python 3.10+, verify `SHA256SUMS`, and keep the matching source. Numerical and history identities are unchanged.

This remains an **alpha prerelease**, with normalized teaching models and bounded local workflows. It does not certify recovery after storage corruption or power loss, hardware stability, general algorithm superiority, independent adoption or human time saved. Earlier versions remain available; PyPI and cloud deployment are outside this release.
