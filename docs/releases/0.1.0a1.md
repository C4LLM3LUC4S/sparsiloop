# SparsiLoop 0.1.0a1

少发一些传感器消息，会让控制误差变大多少？用本地网页调整消息上限、延迟和丢包，比较误差与实际消息数，再把完整结果带走。已有 Q 策略也能复用：先选发送方案，再按预留条件复核，不用重新训练。

Explore how fewer sensor messages affect feedback control. This first alpha combines the local web lab, MFAC/ILC/Q-learning recipes, frozen-policy reuse, planned selection/testing and chronological history in one versioned distribution.

## 下载哪一个 / Which download?

- **`SparsiLoop-0.1.0a1.zip`**：推荐首次使用，含离线 wheel、完整公开源码和开始说明。完整解压后打开 `START_HERE.md`。Recommended offline bundle.
- `sparsiloop-0.1.0a1-py3-none-any.whl`：Python 3.10+ 可安装包，核心无需第三方依赖。Installable core.
- `sparsiloop-0.1.0a1.tar.gz`：源码分发包。Source distribution.
- `RELEASE_INFO.json` 与 `SHA256SUMS`：源码提交、资产大小和校验值。Source and checksum receipt.

Windows 下载后运行 `(Get-FileHash .\SparsiLoop-0.1.0a1.zip -Algorithm SHA256).Hash`，与 `SHA256SUMS` 的同名条目比较。完整 ZIP 内还有逐文件摘要；源码恢复说明在 `source/docs/source-recovery.md`。

## 可以完成什么 / Included tasks

- 在网页比较周期发送与事件发送，查看到达观测、误差、实际消息数和失败。
- 配置经典控制案例；保留训练与测试的区别，固定 Q 策略后用新编号测试。
- 先声明候选、选择和复核条件，保存所有候选与失败，按原计划复核。
- 保存完整历史，在单独评测与后续计划之间接续；坏替换文件不会偷偷提交旧选择。
- 本地接入自己的单输入模型，或只重绘已有结果；保存环境和对应源码。

本版仍是 **alpha 预发行**，对象和接口范围见随包说明。网页不执行上传的 Python；自定义模型使用本地 API。MFAC/ILC 训练、冻结 Q 策略和固定反馈计划不是同一种实验。相同消息上限不等于相同实际成本，完整时段 RMSE 不等于瞬时最大误差。

All examples are mathematical teaching/developer cases, not hardware validation or independent adoption. Unknown values and failures remain explicit. No stability, optimality, paper-reproduction or universal algorithm superiority is claimed. PyPI, cloud deployment and joint controller training/selection/testing are outside this release.
