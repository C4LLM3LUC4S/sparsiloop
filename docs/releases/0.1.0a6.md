# SparsiLoop 0.1.0a6

用自己的模型选方案或复核时，保存位置有问题，就应该在实验开始前知道。这版补上源码示例入口的一处提前检查：输出已经存在，或上级路径是文件时，先停下，不再读取输入、构建模型或计算。

## 下载和开始

- **`SparsiLoop-0.1.0a6.zip`**：完整离线包，包含对应源码、安装包、示例和 `START_HERE.md`。
- `sparsiloop-0.1.0a6-py3-none-any.whl`：Python 3.10+ 独立环境中的核心安装包。
- `sparsiloop-0.1.0a6.tar.gz`：包含本次修正示例的源码分发包。
- `RELEASE_INFO.json` 与 `SHA256SUMS`：核对准确源码提交、文件大小和 SHA-256。旧版本请继续保留。

## 遇到保存路径被占用时

从完整包的 `source/` 目录运行 `python -m examples.planned_model_case select ...` 或 `test ...`，若提示输出目录已存在、上级路径不是文件夹，先保留原报告，再把 `--out` 换成一个新目录。原方案、模型参数和预留编号照旧，不必为了修路径换一组实验条件。具体命令见[同一模型选择与复核](../planned-models.md)。

检查放在路径规范化、输入读取和模型构建之前，避免无效保存位置先消耗一次计算。它不能保证后续磁盘空间、权限或存储始终可用；晚期保存失败仍按实际提示处理。

这是随源码提供的示例入口修复。模型实现、已安装核心的计算和接口、原数值记录及来源身份保持，没有给 wheel 新增算法或扩大模型能力。独立评测的看旧报告、只重绘和另测新条件指引，以及已有本地恢复功能继续保留。

## English

The source-only `examples.planned_model_case` select/test driver now validates its output before path resolution, input reads, model construction or computation. An existing directory or a file-valued parent is rejected early. Preserve the old files and retry the original plan with the same model parameters and reserved IDs into a fresh output folder.

This fixes an example shipped in the source bundle and sdist, not a new algorithm in the installed wheel. The model implementation, numerical behavior, record formats and source identities are unchanged. An early path check does not guarantee later storage availability. Existing standalone report guidance and local save recovery keep their documented limits.

Use the full `SparsiLoop-0.1.0a6.zip` with Python 3.10+, check `SHA256SUMS`, and retain matching source. This remains an **alpha prerelease**. Developer acceptance does not establish independent adoption, human time saved, stability or hardware effects; no PyPI or cloud deployment is included.
