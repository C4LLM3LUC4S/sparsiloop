# SparsiLoop 0.1.0a8

不只是让状态回到零：现在可以给内置位置—速度对象设定一个固定位置目标，比较三种发送方式下的目标误差和实际消息数。这个本地任务使用固定反馈；已有零目标、学习策略和计划复核仍按原约定运行。

## 下载后怎么开始？

- **`SparsiLoop-0.1.0a8.zip`**：完整离线包，含对应源码、wheel、示例方案和顶层 `START_HERE.md`，适合第一次使用。
- `sparsiloop-0.1.0a8-py3-none-any.whl`：Python 3.10+ 核心安装包，无第三方运行依赖；wheel 本身不包含示例 JSON。
- `sparsiloop-0.1.0a8.tar.gz`：对应源码、示例和检查。原版本继续保留。
- `RELEASE_INFO.json` 与 `SHA256SUMS`：核对源码提交、大小和 SHA-256。这些是文件一致性记录，不认证数据来源。

完整解压 ZIP，按顶层 `START_HERE.md` 安装后，在 **ZIP 顶层目录**运行：

```powershell
.\.venv\Scripts\python.exe -I -m event_control_lab.constant_target run --spec source/examples/constant-target.json --out reports/constant-target
```

macOS / Linux 使用 `.venv/bin/python -I`。打开 `reports/constant-target/report.html`，先核对目标和实际初态，再看完整运行状态、目标误差 RMSE、限幅与消息账本。相同发送上限不代表实际通信量相同。完整字段与源码目录命令见[常值目标任务](https://github.com/C4LLM3LUC4S/sparsiloop/blob/v0.1.0a8/docs/constant-target.md)。

## 保存后怎么恢复？

保留整个结果目录、原方案和匹配的发行源码。已有 HTML 可以直接打开；`target-task.json` 是完整任务记录，可以核查并零计算重绘：

```powershell
.\.venv\Scripts\python.exe -I -m event_control_lab.constant_target render reports/constant-target/target-task.json --out reports/redrawn-target
```

这条命令不训练、不仿真，也不重算原指标，保留原执行环境并另记重绘环境。CSV、旧比较、策略或 planned 文件不能替代完整任务记录。本地导出先保存并读回完整记录；之后报告写出失败时，错误会给出**实际保留文件**与重绘命令。如果首次完整保存或读回就失败，不承诺恢复。更多见[保存文件与源码恢复](https://github.com/C4LLM3LUC4S/sparsiloop/blob/v0.1.0a8/docs/source-recovery.md)。

## 这项任务的范围

只支持内置双积分教学模型、预先知道的常值目标和固定反馈。误差坐标为 `e=p-r`，控制器只读取已到达的误差与速度测量。相对触发依据误差—速度范数；状态界限也约束这个误差状态，不能当作实际位置的安全范围。限幅指令与限幅后加入扰动的区间输入分开导出，末行没有推进区间。完整时段 RMSE 沿用梯形积分约定，失败项保持 `null`。

旧数值、模型、冻结策略与计划记录的行为源码保持不变；新任务有独立格式和源码核对。不能把旧学习策略直接用于新目标，也没有扩展到标量平衡输入、自定义对象或时变轨迹。这仍是 **alpha 预发行**，不认证稳定性、硬件效果、独立采用或人工收益；没有 PyPI 或云部署。

## English

This alpha adds a local constant-position task for the built-in double integrator and fixed received-observation feedback. The unchanged engine runs in error coordinates `e=p-r`; a separate CSV reports physical position, target, error, clipped command, disturbed interval input and message events. Relative sending and state limits refer to the error–velocity state, not absolute-position safety. Failed full-horizon metrics remain null.

Use the complete offline ZIP and its top-level installation steps. From that ZIP root, run the installed interpreter with `--spec source/examples/constant-target.json`; a source checkout uses `examples/constant-target.json`. The wheel alone contains no example JSON. Keep `target-task.json`, the original spec and matching source. The `render` command validates and redraws the original record without training, simulation or recomputing metrics. Late export recovery requires a complete record that was already saved and read back successfully.

Previous releases and old numerical, policy and planned identities remain intact. This task does not transfer learned policies or add scalar, arbitrary-model or varying-reference tracking. Developer acceptance is not independent adoption, a stability certificate, hardware validation or measured human benefit.
