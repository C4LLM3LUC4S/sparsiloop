# SparsiLoop 0.1.0a2

选择报告现在能回答“是哪次运行没满足要求？”：展开候选，按原编号查看完整精度的 RMSE、超标、未完整结束、无法判断及保存的原因。报告只解释原记录，不重跑选择、不改选，也不把缺失指标当成零。

This alpha update makes unsuccessful choices inspectable by candidate and declared seed. It preserves the original selection, failures, unknown values and reserved test plan. Numerical, model, controller, policy and history source identities are unchanged from the preceding accepted source.

## 下载哪一个 / Which download?

- **`SparsiLoop-0.1.0a2.zip`**：首次使用建议下载完整离线包，完整解压后打开顶层 `START_HERE.md`。内含 wheel、公开源码和逐文件清单。Recommended complete offline bundle.
- `sparsiloop-0.1.0a2-py3-none-any.whl`：Python 3.10+ 安装包，核心不需要第三方运行依赖。Installable core.
- `sparsiloop-0.1.0a2.tar.gz`：源码分发包。Source distribution.
- `RELEASE_INFO.json` 与 `SHA256SUMS`：对应源码提交、文件大小和 SHA-256。Source and checksum receipt.

Windows 可运行 `(Get-FileHash .\SparsiLoop-0.1.0a2.zip -Algorithm SHA256).Hash`，与 `SHA256SUMS` 的同名条目比较。包内 `BUILD_INFO.json` 标识源码提交，`MANIFEST.json` 覆盖其他 ZIP 成员；这些记录核对一致性，不认证来源。保留旧结果及其对应发行包；0.1.0a1 的说明和资产继续保留。

## 这次改了什么 / Changes

- 选择报告按候选列出每次运行；优先显示未满足要求的编号，保留完整误差值、失败原因与未知值。超过预览数量时仍可下载全部 CSV 和原始 JSON。
- 同一本地服务的六个计算入口共用一个名额，在读取或解析请求正文前检查；忙碌时返回 429 和重试提示，健康和静态读取不占计算名额。
- 默认源码启动器和 `serve` 最多同时处理八个连接，并设读取超时。连接饱和时尽力返回 503，也可能发生连接错误；释放占用后可继续使用，不要求每个过载连接都收到 503。
- 补充从实际决定出发的验收、规模边界和小型问题复现入口。安装包包含这些已接受的改动；报告生成成功仍不代表原要求全部达标。

All examples and checks are original mathematical teaching or developer fixtures, not independent adoption or hardware evidence. Save all candidates, failed runs, the original choice, latest complete history and exact source. A planned test retains the declared policy, thresholds and reserved seeds; redraw only renders saved data. Shared admission and connection caps bound local work, not cloud throughput. This remains an alpha without stability certification, paper-reproduction or universal algorithm-superiority claims. PyPI and cloud publication are outside this release.
