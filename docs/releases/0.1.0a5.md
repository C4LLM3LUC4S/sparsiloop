# SparsiLoop 0.1.0a5

评测报告生成以后，接下来该点哪个文件？这版在本地独立策略评测报告末尾把三件事说清楚：看这次结果、只重绘报告，或另外做一次新测试，避免把它们混在一起。

## 下载和开始

- **`SparsiLoop-0.1.0a5.zip`**：推荐首次使用，包含离线安装包、对应源码、示例和 `START_HERE.md`。
- `sparsiloop-0.1.0a5-py3-none-any.whl`：安装到 Python 3.10+ 独立环境，核心无需额外运行依赖。
- `sparsiloop-0.1.0a5.tar.gz`：源码分发包。
- `RELEASE_INFO.json` 与 `SHA256SUMS`：核对完整源码提交、大小和 SHA-256。旧版本请单独保留。

## 在报告里选下一步

- **只看旧结果**：保留整个输出目录或报告 ZIP，以后打开 `report.html` 就能看，不需要重新测试。
- **只重绘这份报告**：使用完整 `evaluation.json`，按报告里可展开的命令写到新目录。沿用原结果、失败和未知值，不重新训练、评测、生成随机输入或计算指标。
- **另外测新条件**：用本次更新后的 `policy-checkpoint.json` 和未用过的编号。这是一次新测试，不是重绘，也不是原计划的固定条件复核。checkpoint 保留已知编号，但不能代替完整阶段历史；此前的历史与各步结果也要保留，不会自动合并。

完整评测不能被 Q 表、checkpoint 或 `controllers.json` 视图代替。保留匹配的代码和 Python 环境，保存失败后只在终端确认完整记录已保留时，按实际打印命令恢复。原有本地恢复条件继续有效：初写或回读失败不保证恢复，整份本地记录读取仍需内存。详见[保存的策略](../saved-policy.md)和[保存与源码恢复](../source-recovery.md)。

这次只调整本地安全导出的报告说明。原数值、失败/null、声明条件、策略与历史来源身份保持，旧 Python exporter 和临时网页导出继续沿用原合同。没有新增算法、扩大模型范围或承诺网页下载恢复。

## English

The local safe standalone report now separates three next steps: read saved HTML, redraw the complete `evaluation.json` without new computation, or start a new test with the updated checkpoint and unused IDs. An existing checkpoint preserves known IDs but does not replace or merge a separate complete phase history. The report provides specific file links and an expandable redraw command.

Keep the full output and matching source/Python environment. Original results, failures/null, numerical behavior and source identities are unchanged; legacy Python exporters and temporary web exports retain their existing contracts. Local save recovery remains conditional on a confirmed complete readable record, and reading the full local JSON consumes memory.

This is an **alpha prerelease** for local teaching and engineering workflows. Developer checks do not establish independent adoption, human time saved, hardware effects, stability or recovery from storage corruption/power loss. Prior versions remain available; PyPI and cloud deployment are not part of this release.
