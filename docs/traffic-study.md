## 为什么需要第二层对照

单次页面给予三种策略相同发送上限。它能回答同一上限下发生了什么，但事件策略可能实际发送更少。若只把其偏差与用满上限的周期策略比较，不能分清消息数量和发送时刻的影响。

本扫描对每个声明的种子、变化门槛和事件策略保留一个配对：

1. 事件策略使用原发送上限完成仿真，记录实际尝试发送数 `M`。
2. 周期参考将 `M` 个发送机会均匀分布在整个声明时段，使用同一对象、初始条件、增益、检查网格、时域和该种子的外部随机输入。
3. 两边使用全新控制器实例。工厂收到完全相同的事件配置；只改变周期参考的链路预算，防止自定义控制器因读取预算参数而被隐含重新调参。每个原始运行同时记录 `config` 与 `controller_factory_config`。
4. 核对两边实际尝试发送数是否相同、随机输入是否相同以及是否完整完成。全部满足才输出 `事件 RMSE − 周期 RMSE`；负值表示本配对内事件偏差更小。

`M` 是运行后知道的数，而且每个种子和门槛分别设置参考预算。这是**事后描述性对照**，不能作为未知环境中预先选预算的办法。相同尝试发送数不等于相同到达数、年龄、检测计算、字节数或能耗。自有工厂的代码、权重、全局状态与内部随机机制还需要另外记录；接口不能证明用户代码相同或不存在旁路信息。

## 失败、覆盖和扫描选择

失败可能发生在事件侧、周期侧或两侧。周期提前失败时，也可能在用完 `M` 个机会前停止，从而发送量未对齐。所有请求的配对都留在输出；失败轨迹和消息账本也保留。

不可比差值为 `null`，CSV 为空，网页为 `—`。不存在把失败的短时均值或缺失值作为零分的补值。相同发送数的失败运行也不进入完整时段指标比较。

每个策略和门槛的汇总包含全部请求数、可比数、两侧失败数、发送量未对齐数、可比种子列表。只有所有种子都可比，`all_seed_mean_rmse_delta` 才有值；`eligible_subset_mean_rmse_delta` 是可比子集的描述，必须连同覆盖数读取。网页先展示逐项结果，不隐藏失败种子。

程序保存所有声明门槛，不挑选最好的门槛，也不计算显著性、冠军分数或通用优势。这里没有独立调参/测试集划分。要做前瞻性算法比较，下一阶段需要固定调参规则、分离开发种子和测试种子，并保留失败率。

## 操作与导出

网页下方“如果周期策略也只发这么多条呢？”中设置门槛与种子，点击扫描。它们替代单次页面中的门槛与种子，其余参数读取当前左侧设置。扫描后修改设置会明确标记旧结果。

命令行：

```powershell
python -m event_control_lab study --spec examples/traffic-study.json --out runs/traffic-check
```

输出新目录，已有目录拒绝覆盖：

- `study.json`：完整配置、源码指纹、每个种子的外部随机轨迹、每个原始运行、逐项配对和带覆盖数的汇总。
- `comparisons.csv`：所有配对、两侧状态与实际消息账本、位置 RMSE、差值和不可用原因。
- `trajectories.csv`：每个原始运行的真值、位置与速度观测、输入、年龄和每步消息事件，包含失败运行。

Python：

```python
from event_control_lab import Config, StudySpec, study

result = study(StudySpec(config=Config(), thresholds=(0.02, 0.06), seeds=(71, 72)))
```

默认只使用配置里的一个种子；示例 JSON 明确声明三个种子。为限制误操作，每次最多 8 个不同门槛、5 个不同种子、120000 个潜在仿真步；不能靠重复同一种子增加覆盖数。

## 第一组固定工程案例

`examples/traffic-study.json` 声明一阶对象、8 秒、20 ms 网格、发送上限 80、40 ms 延迟、5% 丢包、4 个门槛和种子 20261022/20261023/20261024。共 24 项配对，全部完成且尝试发送数相同。

默认门槛 0.06 下，三个种子的配对位置 RMSE 差值平均为：

| 事件策略 | 可比种子 / 请求种子 | 事件减周期的平均 RMSE 差 |
| --- | --- | --- |
| 绝对变化 | 3 / 3 | +0.023651 |
| 相对变化 | 3 / 3 | +0.016487 |

在这些具体配置中，两种事件启发式的偏差都较相同发送量的周期参考大。这与“事件策略必然更好”的预设不符，也说明只读共同上限下的结果不足以判断通信效率。不能由这三个种子推断所有事件触发方法、环境或控制器的表现。

原始结果保存在本地 `runs/traffic-study-20261022/`，未作为对外发行包或外部独立复现。本轮工程检查覆盖全速零阈值相同轨迹、各对照的随机输入、预算对齐、参考失败、部分种子失败、工厂重置和原始导出。
